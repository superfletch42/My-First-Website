### Discussion of HTML/CSS evolution

### Explanation of 4+ HTML tags
Brief info on some of tha tags I used

---<h1><h2><h3>
Each of these tags are headers. <h1> is the main header and all subsequent tags are sub headers

---<img>

This tag is used to embed an image on a webpage. I used one image as a background for the whole website. These tags typically look like <img src="" alt="">. The src="" is used to import the image from a local folder using the file path or from a website by following the link. The alt="" is used to give a description of the image in the event the image fails to load or a visuelly impaired person is viewing it. alt="" should not be used to give credit to the owner, that should be done preferably under or near the image.

---<div>
A handy tag to create a division or section in the html. a <div> will usually contain <h1><h2><h3> etc. It may also contain <p>, <img> and more. One good reason to use a <div> is for creating id's and or classes so anything you input into the Style sheet can only change that section.

---<a href="">
This is how you create a link. It can be to another webpage connected to the website or directly to another website. A <a href=""> can all be used to turn headers, sentences and even pictures into links. On my own website I use these to go between the pages I have as well as a links to where I found images to credit the owners.
