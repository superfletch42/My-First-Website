### Description on four html tags I used

## 1. Headings and Paragraphs (`<h1>`–`<h5>` and `<p>`)

- **`<h1>`**: Main title of a page (e.g., "A Website About Red Pandas").
- **`<h2>`–`<h5>`**: Subheadings for sections (e.g., "Fun Facts", "Diet of the Red Panda").
- **`<p>`**: Paragraphs for general text content. Contain explanations, descriptions, or information.

- # 2. Images and Media (`<img>` and `<iframe>`)
- 
- **`<img>`**: Displays images such as red pandas, background elements, or maps. Includes `alt` for visuelly impaired used and `src` for the image location from either the pictures folder or online.  
- **`<iframe>`**: Embeds external content. All content I got was from YouTube using a video and live stream.

  ## 3. Lists (`<ul>`, `<ol>`, `<li>`)

- **`<ul>`**: Unordered list
- **`<ol>`**: Ordered list
- **`<li>`**: List items contained within `<ul>` or `<ol>`.  

## 4. Tables (`<table>`, `<tr>`, `<th>`, `<td>`, `<caption>`)

- **`<table>`**: Wraps the entire table.  
- **`<tr>`**: Defines a table row.  
- **`<th>`**: Table header cell, usually bold and centered.  
- **`<td>`**: Table data cell for standard content.  
- **`<caption>`**: Optional title describing the table.

### Discussion of my HTML and CSS evolution.

I started off with a completely blank template, despite the offered ones (I found it really tedious and annoying to have to keep changing thins in the html and css and opted to start from scratch)

My first page took the longest. It contains classes used on all the other pages, like midbox and bottom box. It was pretty much the testing grounds for what I could and couldn't do.
Originally I had a nice yellow-green gradient background but swapped it for a nice bamboo one I'd found.

One of the classes I use 'frame' had a big change. Originally it was just on page 1. It had a background image of a red panda. The reason it was like this was to give a boarder to the picture as well as rounded edge. I thought it would look nicer. When I started reading the assessment criteria I realised I was missing alt text on the images. I had a few tags called 'frame', 'frame1', 'frame2' etc... and no way to give them alt text. After some research I decided to instead make only 1 'frame' tag and would instead insert the picture in through html to give it the needed alt text.

The navigation buttons at the top of the website had a lot of changes. Originally it was in a box that was spread across the whole screen, but I didn't like it. I'd gotten rid of the box, tried pictures in the buttons before I settled on what is now. I was browsing other websites to see how they handled that navigation area. One website I took inspiration from for what my buttons are, is "https://www.pokemon.com/us". I noticed when you changed page, the page button you pressed remained highlighted and I thought it was neat, so I did it myself.

The general colours of my website I messed around with a bit, but ultimately decided on the ligher green, orange and brown colours. They had a nice earthy look to them that I think gives the website great personality and works well with the bamboo background.

Also I only ever used on id and it as for #WR, Just needed to one according to the requirements

All in all, I'm pretty happy with my first website attempt.
