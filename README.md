## Project Structure

```
/RedPandaWebsite
│
├── Page1.html         # Home page: Introduction and fun facts
├── Page2.html         # Conservation page: Threats, diet, and info / link to RPN
├── Page3.html         # Media page: Notable red pandas and videos
├── styles.css         # CSS styling for the entire site
├── Pictures           # Folder containing images used on the website
├── Planning.md        # Markdown containing what I aimed to achieve and by when.
└── Planning stuff     # A terrible named folder with 3 pictures of a (very) rough design I had for the website.
```


## Features

- **Navigation toolbar** across all pages.
- **Responsive design**: Works on desktops and mobile devices (Hopefully, I've not actually tried mobile.)
- **Image frames** with Alt text and references.
- **Fact boxes & content boxes** To seperate information.
- **Table** to show off the diet of a redpanda.
- **Embedded videos**: One documentry of Red pandas and one (Hopefully still up) Live stream of the Trevor Lovejoy zoo's red pandas.
- **Contact form** on the last page.



## Notes on Design

- Background images and content images sourced from [Unsplash](https://unsplash.com/).
- Primary colors: light green (`#C6E068`) for main content, orange (`#eeae2d`) for borders, brown (`#8B4513`) for content boxes.
- Custom classes and IDs used for layout:
  - `.midbox`, `.factbox`, `.box`, `.frame`, `.toolbar`, `.bottompage`
  - `#WR` for photo credit text
- Table styling for diet information.
